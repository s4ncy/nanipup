# Nani Pup — Alpine Care & Stories

Production-ready bilingual Astro website for **https://nanipup.eu**.

## Brand world

**Inspired by Nani** — the dog who gave the project its name, heart and direction.

The site connects:

- **Alpine Care** — private dog care for locals and visitors
- **Nani Adventure Days** — outings inspired by the places Nani loved
- **Nani Memories** — dog + family photography
- **Nani Field Notes** — useful dog-friendly Slovenia knowledge
- **7-day challenge** — a free learning entry point
- **Nani Goods / Nani WALK** — guides, cards, keepsakes and future gear

Main route: **Kranjska Gora → Lake Bled → Bohinj**, with Gorenjska and selected Ljubljana care.

## Run locally

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```

## Publish

The repository includes an automatic **GitHub Pages** workflow.

See [`DEPLOY-GITHUB.md`](./DEPLOY-GITHUB.md) for the exact steps for GitHub and `nanipup.eu` DNS.

## Important launch notes

- The site can be published immediately as a marketing/service website.
- Enquiry forms currently open a pre-filled email to `hello@nanipup.eu`.
- Nani Goods is a catalogue/soft-sell shop until a real checkout is connected.
- Replace/add real brand photography whenever desired; the structure is already ready for it.
